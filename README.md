# Shadow Morph — Shadow Puzzle

모바일 터치와 PC 마우스·키보드를 지원하는 그림자 퍼즐입니다.

기존 V7(19스테이지)을 이 저장소의 `main`으로 이관하고 있습니다.
게임 데이터, 엔진, UI, 자동 테스트와 GitHub Pages 배포 워크플로를 함께 관리합니다.

이 저장소는 게임 코드만 포함합니다. 로그인, 결제, 서버 수집 기능은 없습니다.
브라우저의 진행 저장은 다른 기기와 자동 동기화되지 않습니다.

## 배포

`main`의 검증을 통과한 빌드를 GitHub Pages로 게시합니다.
최초 Pages 활성화에 저장소 관리자 설정이 필요한 경우에는 Actions 실행 결과에 안내합니다.
