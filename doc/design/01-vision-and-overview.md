# 01. 게임 개요와 디자인 철학

> 기준: V8.1.0 / main `5ea02af8c748bfc1207a06932154407bbf3a0232`. 이 문서는 현행 구현을 정리합니다. 기획 의도·제작 기준·후속 검토는 별도로 표시합니다.

## 프로젝트 정의

| 항목 | 현재 정의 |
|---|---|
| 게임명 | Shadow Morph / 저장소명 Shadow_Puzzle |
| 개발 형태 | 1인 개발. 사용자가 대화에서 명시한 제작 형태 |
| 장르·구성 | 1인용 공간 퍼즐, 독립된 40개 방 |
| 핵심 행위 | 상자 그림자를 움직이고 형태를 바꾸며, 빛·장치·발판을 조절한다 |
| 목표 | 실제 상자 전체를 출구 안에 넣고 조작을 마친다 |
| 현재 구현 | 한국어 웹게임. 터치·마우스·키보드 입력을 제공한다 |
| 현재 단계 | 플레이 피드백으로 난이도와 반복감을 다듬는 프로토타입 |

하이 콘셉트: **그림자를 손잡이로 현실의 물체를 바꾸고, 스스로 만든 길로 상자를 출구까지 보내는 퍼즐.** 그림자는 상자가 올라서는 바닥 자체가 아니다. 상자·장치·실제 발판에 영향을 주는 조작 수단이다.

## 디자인 철학과 개발 목표 — 사용자 합의 문안

> 평소 하이퍼 캐주얼 게임을 자주 즐기며, 설명 없이도 바로 이해할 수 있는 단순한 조작과 빠른 재미를 좋아했습니다. 이러한 장점을 퍼즐 장르에 적용해, 누구나 쉽게 시작할 수 있지만 진행할수록 더 깊게 고민하고 스스로 해결 방법을 발견할 수 있는 게임을 만들고 싶습니다.
>
> 앞으로는 짧은 플레이에서도 성취감을 느낄 수 있으면서, 진행할수록 충분한 난이도와 사고의 재미를 제공하는 퍼즐 게임으로 발전시키는 것이 목표입니다.

이 문안은 이 대화에서 사용자가 요청한 수정 방향을 반영한다. 철학을 특정 플랫폼에 한정하거나, 앞으로도 새 기믹을 영원히 추가하지 않는다고 선언하지 않는다. **신규 기믹 0개는 V8.1 캠페인 재편의 범위**다.

## 의도하는 재미

- 관찰: 상자·그림자·광원·장치 사이의 관계를 읽는다.
- 발견: 같은 발판을 이동로에서 형태변형 작업면으로 다시 활용한다.
- 계획: 지금 사용할 설정과 다음 구간에서 필요한 설정을 구분한다.
- 실험: 되돌리기와 재시작으로 부담 없이 다른 방법을 시험한다.

이는 제작 의도이며 재미가 검증됐다는 결과가 아니다. 규칙의 세계 최초 여부, 완벽한 난이도 곡선, 반복감 제거를 보장하지 않는다.

## 제품 범위

현재 상자는 한 개이며 전투, 적, 생명, 제한시간, 별점, 과금, 랭킹은 구현돼 있지 않다. 모든 방은 테스트용으로 선택 가능하다. 앞으로의 스토리·수익모델·출시 플랫폼·대상 연령·상업 일정은 확정된 자료가 없어 이 문서에서 새로 정하지 않는다.
