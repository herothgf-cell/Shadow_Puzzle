# 06. 버튼·그림자 장치·그늘판·문·자동 다리

> 기준: V8.1.0 / main `5ea02af8c748bfc1207a06932154407bbf3a0232`. 이 문서는 현행 구현을 정리합니다. 기획 의도·제작 기준·후속 검토는 별도로 표시합니다.

## 설계 목적

장치를 만지면 실제 길이 바뀌어야 한다. 숫자 ①/②나 SW를 순서대로 방문하는 체크리스트 대신, 작동 주체와 연결 대상을 그림과 케이블로 설명한다.

## 센서 세 종류의 현행 판정

| 요소 | 주체 | 접촉 조건 | 일반적인 데이터 |
|---|---|---|---|
| 노란 ○ 바닥 버튼 | 실제 상자 | 버튼 중심과 상자 사각형 사이의 최단거리 ≤ `(r 또는 28)×0.55` | `accept:'box'` |
| 보라 ◇ 점형 장치 | 상자 그림자 | 장치 중심이 그림자 타원 안에 들어감 | `accept:'shadow'`, w/h 없음 |
| 긴 보라 그늘판 | 상자 그림자 | 그림자 **중심**이 판 중심±w/2,±h/2 범위 안 | `accept:'shadow'`, w/h 있음 |

그림자는 바닥 버튼을 누르지 않고, 상자는 그림자 전용 센서에 직접 영향을 주지 않는다. 발판 그림자는 어느 센서에도 접촉하지 않는다. 여러 상자 그림자 중 하나라도 닿으면 충족하며, A/B 전용 판정은 없다.

바닥 버튼의 렌더링 반경과 실제 눌림 반경은 같지 않다. 점형 그림자 센서는 `r`을 그림자 접촉 반경으로 쓰지 않는다. 그늘판은 타원 전체를 덮거나 면적의 일정 비율을 채우는 판정이 아니다.

## 래치와 유지형

`latch:true`는 한 번 접촉하면 현재 시도에서 켜진 기록이 남는다. `latch:false`는 현재 접촉이 있어야 활성 상태다. 센서의 외형 종류와 활성화 지속 방식은 별도의 데이터 속성이다.

| 지금 접촉 | 과거 래치 기록 | 센서 활성 |
|---|---|---|
| 있음 | 무관 | 활성 |
| 없음 | 있음 | 활성 |
| 없음 | 없음 | 비활성 |

래치 기록은 되돌리기로 이전으로 돌아가거나 방을 재시작하면 바뀐다. 새로고침 시에는 유효한 저장에서 복원한다.

## 연결된 현실 장치

각 장치는 `sensorId` 하나로 센서 하나를 참조한다. 센서 하나가 여러 장치를 구동하는 것은 가능하지만, 장치 하나에 AND/OR 복합 조건을 주는 구현은 없다. 복합 문제는 독립된 문과 센서의 실제 배치로 만든다.

- `type:'gate'`: 닫혀 있으면 현실의 사각형 장애물, 열리면 그 장애물이 제거된다.
- `type:'bridge'`: 닫혀 있으면 끊긴 길을 나타내는 사각형 장애물, 켜지면 그 장애물이 제거되고 다리로 그려진다.

두 종류 모두 엔진은 `state.devices[id]`로 통과 여부를 결정한다. 다리 위치를 별도 영구 pit으로 중복 덮으면 다리를 켜도 pit이 남는다. 작성자는 해당 구간을 pit 목록에서 비워두거나 올바른 지형 구성으로 정의해야 한다.

## 끼임 방지와 적용 순서

장치 상태는 `센서 활성 OR (이미 열렸고 현재 상자와 겹침)`으로 갱신한다. 따라서 그늘이 사라져도 통과 중인 상자를 문으로 끼우거나 이미 열린 다리 위 상자의 지지를 즉시 없애지 않는다. 이 안전장치는 현재 코드상 gate와 bridge 모두에 적용된다.

닫혀 있던 장치가 미래 이동 후보와 겹친다는 이유만으로 열리지는 않는다. 현재 상태의 충돌을 통과한 뒤 센서를 갱신하므로 빠른 드래그로 닫힌 문 너머로 순간이동할 수 없다. 상자가 장치에서 완전히 벗어나고 전원도 없으면 닫힌다.

열림/닫힘 애니메이션은 약 450ms, 케이블 신호는 약 850ms지만 통과 판정은 장치 상태가 갱신되는 순간 바뀐다. 애니메이션이 끝날 때까지 기다리는 별도 퍼즐 타이밍은 없다.

## 피드백

상자 버튼은 원형, 점형 장치는 마름모, 유지형은 길쭉한 점선 판으로 구분한다. 장치에서 문/다리까지 꺾인 케이블을 표시한다. 작동 시 버튼 색·체크와 연결 상태가 바뀌고 '문이 열렸어요/다리가 펼쳐졌어요'를 안내한다.

## 제작 기준

문을 열기 위한 작업 위치는 실제 지형으로 확보하게 한다. 장치를 모두 방문해야 하는 추가 승리 조건을 넣지 않는다. 유지형 문 문제는 안전장치를 없애거나 두 손가락 동시 조작을 요구하지 않는다. 다른 정상 해법은 허용한다.

현재 활성 캠페인에서 래치 버튼은 2번부터, 점형 그림자 센서는 9번부터, 유지형 그늘판은 29번부터 등장한다.
