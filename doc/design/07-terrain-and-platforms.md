# 07. 지형·빈 공간·조절 발판

> 기준: V8.1.0 / main `5ea02af8c748bfc1207a06932154407bbf3a0232`. 이 문서는 현행 구현을 정리합니다. 기획 의도·제작 기준·후속 검토는 별도로 표시합니다.

## 지형의 역할

| 요소 | 상자 | 그림자/빛 | 발판과 관계 |
|---|---|---|---|
| 일반 바닥 | 이동·변형 가능 | 위치 계산 가능 | 바닥과 겹쳐도 됨 |
| 돌벽 | 충돌 | 가림·충돌 계산 없음 | 발판 확대·축소 중 겹치면 정지 |
| 빈 공간 `kind:'pit'` | 지지 없으면 이동 불가 | 통과 가능 | 실제 발판이 덮은 부분만 통과 가능 |
| 닫힌 장치 | 충돌 | 접촉 센서는 별도 | 발판 변형의 장애물 |
| 출구 | 장애물 아님 | 그림자 도착은 무효 | 상자 전체 포함을 판정 |

바닥을 50 단위 격자로 그리지만 이동은 칸 단위가 아니다. 떨어지는 애니메이션이나 사망은 없고, 지지가 없는 위치로 가지 못하게 한다.

## 조절 발판의 규칙

발판은 중심과 방향이 고정된 별도 물체다. 상자를 발판으로 바꾸는 기능이 아니다. 발판 A/B를 선택해 그림자 손잡이·패드·슬라이더·짧게/중간/길게 버튼으로 길이를 바꾼다. 방향은 x 또는 y이며 자유 이동·회전은 없다.

길이 L, 면적 A일 때 폭은 `A/L`이다. 가로 발판은 `(w,h)=(L,A/L)`, 세로 발판은 `(A/L,L)`이다. 중심을 고정한 채 양끝이 함께 움직인다. 각 발판의 면적은 독립적이며 발판끼리 길이나 자원을 주고받지 않는다.

예: 현재 6번 방 A의 면적은 50000이다. 길이 180이면 폭 약 277.78, 길이 500이면 폭 100이다. 길게 만들수록 멀리 이어지지만 작업 공간은 좁아진다. 실제 정답 길이는 각 방의 땅 위치와 상자 형태에 따라 달라진다.

## 실제로 바닥이 되는 범위

`solids()`는 pit에서 각 발판의 실제 직사각형을 빼고 남은 조각을 충돌 대상으로 사용한다. 따라서 발판 여러 개와 원래 땅의 합집합으로 상자를 받칠 수 있다. 발판 하나가 상자 전체를 받쳐야 한다는 별도 조건은 없다. 단, 전체 상자가 어떤 바닥에도 지지되지 않는 틈을 겹치면 이동할 수 없다.

돌벽과 닫힌 장치는 발판이 덮어도 제거되지 않는다. 발판은 점수용 그림이 아니라 실제 통과 가능한 영역을 바꾼다.

## 안전한 길이 변경

범위는 발판별 `minLength`~`maxLength`다. 변경 중의 돌벽·닫힌 장치·월드 경계를 검사한다. 현재 상자가 있는 자리의 바닥이 사라지면 허용 길이 경계까지만 바꾼다. 상자를 임의로 밀거나 함께 운반하지 않는다.

반환 이유는 `stone`(벽/경계 등), `support`(상자 지지)로 UI에서 구분한다. 발판 위에서 줄이기 자체가 금지된 것은 아니다. 충분히 지지되는 동안에는 줄여서 넓은 작업면을 만드는 풀이가 가능하다.

이미 늘어난 발판 위로 유지형 문이 나중에 닫히는 상태가 존재할 수 있다. 닫힌 문은 계속 상자를 막는다. 저장 복원은 이 정상 상태를 거절하지 않도록 발판의 영구 돌벽·경계를 검사하고, 상자는 실제 닫힌 장치를 포함해 검사한다.

## 안내값과 충돌의 차이

`spanStart/spanEnd`는 발판이 도달해야 할 두 기준점이다. `platformInfo.connected`는 길이가 그 두 지점에 닿는지, `fits`는 연결과 상자 횡방향 크기를 함께 확인한다. 이것은 사용자 안내용 요약이다. '연결 완료'가 주변 돌벽·닫힌 문까지 통과 가능하게 하지는 않는다. 최종 판정은 실제 지형 충돌이다.

`purpose:'worksite'`를 사용하면 UI는 양쪽 강둑 연결 대신 작업 자리 확보로 설명할 수 있다. **지원되는 필드지만 현재 활성 40방에는 이 값이 없다.** 옛 방이나 후속 레벨에 사용하려면 별도로 확인한다.

## 기획상 활용

6번은 길 만들기, 7번은 길이와 폭, 8번은 출구 형태와 폭의 양립, 11번은 문을 먼저 열어 확장 공간 확보, 13번은 서로 다른 방향의 두 길, 22번은 발판을 작업면으로 다시 사용한다. 35~40번은 여기에 유지형 문과 광원 역할 전환을 결합한다.

현재 후반 모든 방이 '발판 재설정 필수'인 것은 아니다. 같은 풀이를 길게 반복시키지 않고, 각 방에서 어떤 설정을 언제 다시 써야 하는지 구분한다.
