# 09. 스테이지 구성·학습·난이도·중복 방지

> 기준: V8.1.0 / main `5ea02af8c748bfc1207a06932154407bbf3a0232`. 이 문서는 현행 구현을 정리합니다. 기획 의도·제작 기준·후속 검토는 별도로 표시합니다.

현재 배열은 V8.1의 설계상 상대 난도 추정이다. 매 방의 해결 시간을 실측해 단조 증가를 입증한 결과가 아니다. 자유 이동/빛축 이동은 각 방 `axisMovement`를 확인한다. 예를 들어 20·21은 빛축 이동이지만 22는 자유 이동이다.

## 재배치의 이유

사용자 피드백은 이전 11~12의 두 광원/그늘 유지가 13~14 기본 변형보다 어렵고, 비슷한 맵이 많으며 후반에도 쉬운 문제가 많다는 것이었다. '12번까지 모든 기믹을 설명'보다 실제 사고 부담을 우선하도록 바꿨다.

기존 13→현재 5, 14→10, 11→23, 12→29다. 28개 방은 ID와 지형을 유지해 재배치했고 12개는 새 ID로 교체했다. 교체 번호는 25~28, 30, 34~40이다. 순서만 달라진 방과 실제로 새 문제가 된 방을 구분한다.

## 난이도 판단 기준 — 제작 기준

기믹 수나 해답 입력 횟수만으로 등급을 정하지 않는다. 동시에 유지할 관계, 선행 조건의 깊이, 출구에서의 역산, 설정을 다시 바꿔야 하는 이유, 대안 경로 비교를 함께 본다.

'그림자가 한 번 닿으면 끝'과 '다른 작업 중 계속 판에 남아야 함'은 다르다. 두 광원이 있다는 이유만으로 최고난도라고 하지 않고, 두 축이 왜 모두 필요한지 본다. 정확한 위치를 알아도 손가락으로 맞추기 어려운 경우는 추론 난도가 아니라 조작성 문제로 기록한다.

## 중복 방지 — 제작 기준

맵 실루엣이 달라도 행동의 이유가 같으면 반복일 수 있다. 새 방마다 '이전과 달리 발견할 관계'를 한 문장으로 적는다. 벽 위치만 이동, 좌우 반사, 버튼까지 거리 증가만으로 새 고난도를 만들지 않는다.

현재 22의 작업대 발상과 35·40은 같은 기법을 재사용하지만 후자는 문 유지·확장 조건을 추가했다. 이 차이가 실제 재미로 느껴지는지는 플레이테스트에서 확인한다. 지형 중복 검사는 체감 반복감의 부재를 증명하지 않는다.

## 해법과 우회

벽·센서·지지 규칙을 지킨 대체 해법은 허용한다. 학습 목표를 전혀 사용하지 않고 쉽게 끝난다면 숨겨진 체크포인트를 추가하지 않고 지형이나 배치 구간을 재검토한다. 센서 무력화와 발판 재설정 생략 검사는 작성된 경로의 의존성을 보여줄 뿐 모든 다른 해법을 배제하는 증명은 아니다.

## 방 제작 양식

방 ID와 이름, 현재 번호, 이동/변형 규칙, 지형, 빛, 센서-장치 연결, 발판, 핵심 발상, 잘못 시도하기 쉬운 접근, 안내/tip, 선택 힌트/hint, 완료 의미/meaning, 실제 입력 해답, 정상 대체 해법, 모바일 입력 여유를 기록한다.

ID는 번호가 아니다. 지형과 판정 의미가 그대로인 재배치는 ID를 유지한다. 새 퍼즐로 교체할 때는 새 ID를 발급해 이전 위치·완료를 잘못 이어받지 않게 한다.
