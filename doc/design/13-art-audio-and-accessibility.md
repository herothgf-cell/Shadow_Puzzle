# 13. 그래픽·연출·사운드·접근성

> 기준: V8.1.0 / main `5ea02af8c748bfc1207a06932154407bbf3a0232`. 이 문서는 현행 구현을 정리합니다. 기획 의도·제작 기준·후속 검토는 별도로 표시합니다.

## 현재 그래픽 표현

현재 게임은 HTML Canvas 2D의 도형과 텍스트로 표현한다. 외부 모델·스프라이트·물리적 광선 추적을 쓰는 3D 게임이 아니다. 웹 셸의 아이콘·정적 실행 전 미리보기도 코드 기반 도형이다.

| 요소 | 시각 언어 | 의미 |
|---|---|---|
| 전체 배경 | 짙은 남색 `#10151e`, 어두운 패널 | 도형과 상태 대비 |
| 상자 | 노랑/금색 그라데이션 | 실제로 이동하며 출구에 들어갈 물체 |
| 상자 그림자 | 어두운 보라 타원, 점선 테두리 | 조작·원격 접촉 |
| 출구 | 민트색 점선 사각형 | 상자 전체가 들어갈 목표 |
| 발판 | 청록색 직사각형과 판재 줄무늬 | 실제 지지 영역 |
| 돌벽 | 회청색 채움과 사선 | 통과/확장 불가 |
| 빈 공간 | 더 어두운 채움과 물결을 연상시키는 사선 | 지지 필요 |
| 바닥 버튼/점형 장치/유지판 | 원/마름모/긴 점선 영역 | 작동 주체와 유지 조건 구분 |

색만이 아니라 모양·라벨·연결선을 함께 사용한다. 선택된 그림자/발판은 더 밝고 두꺼운 외곽선을 사용한다. 움직이는 빛과 고정광도 라벨로 구분한다.

## 연출

센서와 장치의 연결은 꺾인 케이블로 표시한다. 작동하면 연결선을 따라 신호를 보이고 문이 양쪽으로 열리거나 다리가 펼쳐지는 도형 연출을 쓴다. 장치 애니메이션 약 450ms, 케이블 약 850ms이며 물리 판정과 별개다.

완료 창에는 해당 방의 해결 의미를 보여준다. 죽음/낙하/점수 폭발 연출은 없다. 정적 썸네일은 실제 방 데이터로 렌더링하므로 홍보용 그림과 구분된다.

## 커버와 실제 플레이의 구분

대화에서 만든 입체풍 커버 이미지는 홍보 시안이다. 현재 저장소의 실제 플레이는 위 도형 기반 2D 화면이며, 아치형 3D 다리·계단·그림자 그 자체를 걸어가는 기능은 구현돼 있지 않다. 홍보물은 실제 스크린샷을 대체하지 않는다. 커버 파일의 저장소 자산 편입·최종 채택 여부는 이 문서에서 결정하지 않는다.

## 사운드와 서사 상태

현재 소스에는 배경음, 효과음, 오디오 설정 시스템이 없다. 작동음을 제작 완료된 요소로 기록하지 않는다. 이야기·등장인물·대사·챕터 서사도 현재 코드/기획에서 확정되지 않았다. 방의 의미 문장은 해결 원리를 설명하는 문구이지 스토리 진행 시스템이 아니다.

후속 사운드 도입은 별도 결정 사항이다. 음원 출처, 사용 범위, 음소거, 진동, 자동재생 대응은 구현 전 기획과 검증이 필요하다.

## 접근성과 조작성

현재 버튼과 슬라이더의 접근성 이름, 포커스 표시, 상태 문구의 aria-live, 키보드 입력, 정밀 조작, reduced-motion을 지원한다. 사운드 없이 플레이하는 구조다. 다만 색각 유형별 실측, 스크린리더로 공간 퍼즐 완주, 실제 기기별 터치감이 검증됐다고 주장하지 않는다.

기획상 목표는 손가락 정밀도를 난이도로 삼지 않는 것이다. 작은 화면의 과도한 라벨 중첩, 선택 대상을 잘못 잡는 문제, 빈 실행 화면은 조작성 결함으로 기록한다.
