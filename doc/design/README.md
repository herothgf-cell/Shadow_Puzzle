## 범위와 읽는 방법

요청한 경로는 **`doc/design/`**다. 기존 **`docs/`**의 기획·릴리스·검증 이력은 옮기거나 삭제하지 않는다. 이 폴더는 그 이력과 현재 실제 코드/데이터를 대조한 **현행 요소별 기획서**다.

본문의 규칙·수치·화면은 현재 구현을 설명한다. **기획 의도/제작 기준**은 왜 그렇게 만들고 어떻게 평가할지를 설명하며, **후속 검토/미구현**은 현재 기능이 아니다. 코드에 없는 내용을 확정 기능으로 채우지 않는다. 출처가 없는 수익모델·서사·일정·대상 연령을 새로 정하지 않는다.

원하는 경험은 '쉽게 시작하고, 스스로 해결법을 발견하며, 짧은 플레이에서도 성취감을 얻는 퍼즐'이다. 철학은 특정 플랫폼이나 영구적인 기믹 추가 금지에 한정하지 않는다. V8.1의 신규 기믹 0개는 해당 재편 작업의 범위다.

## 반드시 구분할 것

| 혼동하기 쉬운 설명 | 현재 정의 |
|---|---|
| 그림자가 다리다 | 상자 그림자는 조작/접촉 수단. 실제 지지는 자동 다리와 조절 발판 |
| 그림자를 늘리면 크기가 커진다 | 상자와 발판은 각각 면적을 보존하며 폭/높이 또는 길이/폭을 교환 |
| 그림자 A를 고정하고 B를 움직인다 | 두 그림자는 같은 상자를 따라 함께 움직임 |
| 그늘판은 그림자 전체로 덮는다 | 긴 판은 그림자 중심, 점형은 장치 중심이 타원 안인지 검사 |
| 발판 그림자도 센서를 누른다 | 센서에 닿는 그림자는 상자 그림자뿐 |
| A는 항상 가로축이다 | 축은 현재 광원과 상자의 위치 관계로 결정 |
| 모든 버튼을 눌러야 완료다 | 실제 상자 전체 출구 포함과 충돌 없음만 판정 |
| 번호를 옮기면 새 방이다 | 같은 ID 재배치와 새 ID 지형 교체를 구별 |
| 테스트 통과면 재미가 검증됐다 | 해결 가능성/호환성/체감 난이도는 별도 검증 |
