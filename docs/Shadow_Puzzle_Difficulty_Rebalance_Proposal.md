# Shadow Puzzle — 난이도 우선 재배치 및 유사 풀이 정리안

상태: 사용자 플레이 피드백과 현재 main의 레벨·제작용 해답을 검토한 수정 제안. 코드 변경, main 푸시, 새 배포는 하지 않았다.
기준 저장소: herothgf-cell/Shadow_Puzzle
검토 커밋: 984bcb703ecb393383d4ca2f3fe571598ed6228c
범위: 총 40개 방 유지, 신규 기믹 0개. 난이도 순서를 우선하고 같은 난이도 안에서 지형과 풀이 반복을 줄인다.

## 1. 이번 피드백으로 폐기하는 기준

- '12번까지 모든 기믹을 소개해야 한다'는 기준을 폐기한다. 어려운 기믹은 중후반에 처음 나와도 된다.
- '장치가 많다', '이동이 길다', '제작자가 고난도라고 이름 붙였다'를 난이도의 근거로 삼지 않는다.
- 해답 하나의 실행 성공을 난이도, 최단해, 우회 해법 부재 또는 재미의 검증으로 표현하지 않는다.
- 회전·반사에 대해 지형 그림이 달라도 같은 판단을 반복하면 중복 후보로 본다.

## 2. 소스에서 확인한 현재 상태

### 11~14의 역전
- 현재 11 '두 빛의 선택': 두 고정 광원, 축 이동, 상자 위치에 따른 이동축 선택.
- 현재 12 '선택하지 않은 그림자': 위 조건에 더해, 상자를 움직이는 동안 다른 그림자 중심이 유지형 그늘판 안에 있어야 한다.
- 현재 13 '꺾기 전에 바꾸기': 한 광원, 자유 이동, 센서·장치 없음. 가로/세로 형태 변경이 중심이다.
- 현재 14 '누가 눌러야 할까': 한 광원, 자유 이동. 두 장치는 모두 한 번 켜지면 유지되는 형태이다.

따라서 11~12 뒤에서 다시 쉬운 이동·변형 조합으로 돌아오는 구성이 실제로 존재한다. 사용자 체감 피드백과 일치하는 구조적 설명이다. 전체 사용자 난이도 순위를 측정했다는 의미는 아니다.

### 후반 검토 우선 대상
- 29 '몸을 옮기지 않고 닿기': 작성된 해답은 형태 변경 → 건너기 → 기본형 복귀가 중심이다. 발견의 신선함과 후반 난도는 구분해야 한다. 초중반 응용으로 이동할 유력 후보.
- 22·23·38·39: 접근 순서, 왕복, 독립된 준비를 포함하지만 조작 길이가 늘어나는 것만으로 어렵다고 볼 수 없다. 더 쉬운 경로와 선행 관계를 우선 재검사한다.
- 30: 유지형 문과 고정형 다리가 있으나, 각각을 순차 처리하고 그늘 유지 범위가 넉넉하면 후반에서 쉬울 수 있다.
- 28·37: 두 고정 광원의 축 교점을 찾는 발상을 공유한다. 조작 횟수가 짧다는 이유로 쉽게 분류하지 않는다. 교점 발견 난도를 비교하고, 둘 중 하나는 다른 판단을 요구하도록 바꾼다.
- 26·31·35: 발판을 줄여 작업 폭을 확보하는 발상을 공유한다. 학습 1회 이후에는 왜 다시 설정해야 하는지가 달라야 한다. 버튼·왕복만 추가한 확장은 교체 후보이다.

## 3. 난이도 판단 축

| 판단 축 | 낮은 부담 | 높은 부담 |
|---|---|---|
| 조작 대상 | 상자 하나의 형태/이동 | 상자·발판·빛을 목적에 따라 전환 |
| 위치 판단 | 한 번 접촉하면 결과가 유지 | 다른 행동 중에도 그림자 위치 조건을 유지 |
| 이동 계획 | 자유 이동, 현재 보이는 길 | 두 광원의 축과 도착 위치를 함께 판단 |
| 설정의 재사용 | 한 번 설정하면 끝 | 같은 장치를 다른 목적의 설정으로 되돌려 사용 |
| 선행 관계 | 한 장애물씩 독립 처리 | 출구 조건을 거슬러 준비 위치·지지면·유지 범위를 계획 |

이 표는 설계용 비교 기준이지, 실제 플레이로 측정한 점수가 아니다. 기믹 종류 하나로 난이도를 자동 확정하지 않는다. 특히 좁은 그늘판의 픽셀 조준은 사고 난도와 별도로 불편함으로 기록한다.

### 그림자 특정 위치의 부담 구분
1. 넓은 영역에 한 번 닿기.
2. 한 광원을 옮겨 장치에 한 번 닿기.
3. 상자와 광원 위치를 모두 조합해 닿기.
4. 그림자 중심을 그늘판 안에 유지하면서 다른 행동을 하기.
5. 두 그림자의 움직임과 유지 조건을 같이 관리하기.

위 순서는 기본 가설이다. 맵의 공간, 허용 범위, 해법 가시성에 따라 순서가 달라질 수 있다.

## 4. 새 40개 캠페인의 구간 제안

정확한 기존 번호→새 번호 40개 확정표는 재설계와 비교 플레이 후 작성한다. 아래는 먼저 적용할 배치 원칙이다. 새 번호가 난이도의 증거가 되지는 않는다.

| 새 구간 | 주된 내용 | 배치 원칙 |
|---|---|---|
| 1~8 | 이동·가로/세로·바닥 버튼·발판 길이/폭 | 단일 목표와 즉시 보이는 결과. 두 광원 제외 |
| 9~16 | 단일 그림자 접촉, 문·다리·발판의 선행 관계 | 한 번 작동하면 유지되는 장치가 중심. 이동량만 긴 방은 압축 |
| 17~22 | 한 광원의 이동·이동축·안전한 변형/작업 위치 | 그림자 위치와 상자 위치를 연결해 생각하는 구간 |
| 23~28 | 두 광원 선택·축 교점·경로 계획 | 기존 11 같은 문제는 이 구간의 도입 후보. 단순 고정 버튼 방으로 회귀 금지 |
| 29~34 | 유지형 그늘판·두 그림자·역할 전환 | 기존 12 계열은 이 구간 후보. 유지 범위를 과하게 좁혀 난이도를 만들지 않음 |
| 35~40 | 유지 조건·발판 작업면·이동축의 재설정 | 독립된 간단한 문제를 직렬로 나열하는 대신 조건이 실제로 서로 영향을 주어야 함 |

두 광원이 없어도 사고 부담이 높은 발판 문제는 후반에 남길 수 있다. 이 구간은 기믹별 의무 챕터가 아니라 난도 추정의 출발점이다. 어려운 규칙의 첫 방에서는 조작을 알려주되 여러 독립 튜토리얼을 연속 배치하지 않는다.

### 우선 이동 후보
- 현재 13 → 새 4~6 중 검토. 초반 형태 조합 연습.
- 현재 14 → 새 10~12 중 검토. 고정형 장치의 역할 구분.
- 현재 29 → 새 12~16 중 검토. 형태로 그림자 접촉하기.
- 현재 11 → 새 23 전후 검토. 두 이동축 선택의 도입.
- 현재 12 → 새 29~30 전후 검토. 다른 그림자의 유지 범위를 고려하는 도입.
- 현재 28/37, 26/31/35는 번호 이동만 확정하지 않고 중복 풀이 검토 후 존치·교체를 결정.

## 5. 유사 맵 판정

각 방에는 지형 사진 대신 다음을 함께 기록한다.
- 진입부터 출구까지 연결 구조: 갈림, 중앙 공간, 막다른 작업실, 순환, 단절된 섬 등.
- 반드시 발견해야 하는 한 가지 생각.
- 상태 변화 순서와 다시 설정해야 하는 대상.
- 기존 방과 다른 실패 원인 및 복구 방식.

예: '낮은 문 → 가로, 좁은 문 → 세로'는 벽 모양을 바꿔도 같은 풀이이다.
예: '발판을 늘려 건너기'와 '건넌 발판을 줄여 작업면 만들기'는 다른 풀이이다.
예: 이미 작업면 활용을 익힌 뒤 '같은 작업면 + 멀리 있는 버튼 방문'만 추가하면 반복 후보이다.

동일한 발상을 반복하는 방은 새 선행 관계가 없으면 합치거나 교체한다. 합쳐 남은 번호는 다른 기존 기믹 조합의 문제로 채우되, 40개를 채우려고 비슷한 문제를 재사용하지 않는다. 새 판단이 검증되지 않으면 후반 방 완료로 처리하지 않는다.

## 6. 후반 재설계의 합격 기준

### 제외해야 할 쉬운 진행
- 필요한 장치를 모두 미리 켜고 나면 생각할 일이 없어지는 진행.
- 발판을 모두 최대 길이로 만든 뒤 평소처럼 이동하면 끝나는 진행.
- 다음 출구에 가까워지는 행동만 계속해도 풀리는 종합 문제.
- 유지형 장치를 사실상 신경 쓰지 않고 통과하는 진행.
- 그 방이 앞방과 다른 판단 없이 이동 거리만 더 요구하는 진행.

이것들은 진단용 전략이다. 하나의 전략으로 풀린다고 자동으로 무효 처리하지 않는다. 합리적인 쉬운 해법은 정상 해법으로 인정하고, 그 결과 방을 앞쪽에 놓거나 지형을 바꾼다. 숨은 방문 횟수·행동 순서 검사로 쉬운 해법을 막지 않는다.

### 원하는 후반 판단
- 지금 필요한 연결과, 이후 형태를 바꾸는 데 필요한 작업 폭이 달라서 설정을 다시 해야 한다.
- 한 번 켜면 남는 장치와 지금 유지해야 하는 조건을 구분해야 한다.
- 지금 선택한 이동축이 다음 작업 위치와 그림자 유지 범위를 모두 충족해야 한다.
- 준비는 원격으로 가능하므로 '장치 옆에 가야 설정 가능'을 가짜 순서 조건으로 쓰지 않는다.
- 같은 상자를 따라 두 그림자가 함께 움직이는 현행 규칙 안에서 경로를 구성한다.

타이머, 정밀 드래그 강제, 이동 횟수 제한, 새 기믹, 안전장치 삭제는 제외한다.

## 7. 적용 순서와 검증

1. 현재 40개 방을 사용자 체감과 정적 구조로 1차 분류한다. 평가와 추정은 구분한다.
2. 11~14 역전처럼 명확한 배치 문제부터 수정한다.
3. 29 등 후반의 짧은 독립 응용 문제를 앞쪽 후보로 내린다.
4. 28/37과 26/31/35처럼 풀이 골격을 공유하는 그룹을 비교하고 중복을 교체한다.
5. 새 23, 30, 36, 40 대표 문제를 먼저 비교 플레이한다. 재미·불편·실제 사고 난도를 기록한다.
6. 검증된 상대 난도에 맞춰 40개 순서를 확정한다. 동일 난도 내에서만 지형·풀이 다양성으로 순서를 조정한다.
7. ID 기반으로 저장을 이전한다. 재배치만 한 방은 ID 유지, 실제 다른 방으로 바꾼 경우 새 ID를 사용한다.
8. core/level/저장 검사를 유지하고 40개 브라우저 입력 경로를 갱신한다. 모바일·PC 화면과 정밀 조작 부담도 별도로 확인한다.
9. 구현 승인 후 문서·레벨·해답·테스트를 같은 main 변경에 반영한다. CI가 통과한 배포의 commit/version을 공개 URL에서 확인한다.

### 플레이테스트 기록
힌트 없이 최초 해결하는 시간, 스스로 해결했는지, 시도한 설정의 종류, 막힌 이유(추론/조작/안내), 쉬운 우회 해법을 분리 기록한다. 드래그 횟수와 이동 거리는 부차 지표이다. 기믹을 익힌 사람이 바로 풀어버리는 후반 방은 이름과 번호에 상관없이 강등 또는 재설계한다.

## 8. 범위와 한계

이번 검토는 main 데이터와 작성된 해답을 읽은 설계 검토이다. 새 배치의 최적해 탐색이나 신규 플레이테스트를 수행한 결과가 아니다. 따라서 구간과 이동 후보는 제안이며, 모든 사람에게 단조롭게 어려워진다고 보장하지 않는다. 현재 main과 공개 사이트는 변경하지 않았다.
